# Plain photo slots

Put plain versions (no event artwork) of these photos here, with exactly these names:

- `cloud9-workshop.jpg`: the workshop shot (students at laptops)
- `cloud9-team.jpg`: the team photo

When a file exists here, the site uses it everywhere in place of `pics/<same name>`
(home, projects, experience, about). Delete it to go back to the original.

Keep them landscape and under ~300 KB (they display at about 650px wide).
