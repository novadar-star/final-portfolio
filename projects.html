AI Jobs Scraper & Resume Optimizer 🔗

applying to jobs manually was slow, so i built a Slack-triggered pipeline that scrapes listings and runs an AI agent to score them against my resume. the scraping part was straightforward. the interesting part was that the AI kept sending back malformed JSON — sometimes wrapped in markdown fences, sometimes with trailing commas, sometimes just broken.

so i wrote a parser: strip markdown fences first, then try JSON.parse, then fall back to regex extraction, then apply safe defaults if everything fails. built as a Function node in n8n. the workflow kept running through all of it. i later reused that exact parser pattern in a public webinar, which also meant sanitizing a hardcoded API key from the workflow JSON before sharing — a useful reminder about the gap between "works on my machine" and "shareable artifact."

automation · outbound · 2026

GTM Signal-Based Outbound Pipeline 🔗

a pipeline that ingests buying signals, scores leads, enriches contacts via Hunter.io, validates emails, builds ICP profiles, and generates personalized outbound drafts. the email validation part had an interesting constraint: i originally planned to use NeverBounce, then found out it had usage costs at this volume.

ended up replacing it with a free MX record lookup plus a regex format check. catches the same invalid domains, costs nothing, and is more debuggable than a black-box API. also hit a JSearch nesting bug where the job data came back in an unexpected structure — fixed with a normalization step before scoring. both of those felt like better solutions than the originals.

Internal AI Advisor — Eskwelabs 🔗

three AI advisor personas that pull context from Google Docs and stream Gemini responses in real time. built during my internship and shipped to the production intern cohort — meaning people on the team used it daily.

Google OAuth with a domain allowlist so only @eskwelabs.com accounts can log in. Supabase with Row Level Security for per-user conversation history. the trickiest part was passing the auth JWT correctly from Google OAuth through to Supabase on every request — easy to get conceptually right, annoying to get technically right.
